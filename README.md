# Bode Care

Mobile-first Next.js prototype for a client-facing fitness coaching app.

## What is included

- Welcome, onboarding, questionnaire, today, nutrition, training, progress, and profile routes.
- PWA-ready metadata and mobile safe-area layout.
- Typed mock data for user, coach, daily plan, meals, workout, exercises, and progress.
- Dark premium visual direction with app-like navigation, bottom sheets, sticky panels, and workout logging.

## Commands

```bash
npm run dev
npm run lint
npm run build
```

The app runs at `http://localhost:3000`.
